Generar C

El código C son datos de ALMA: se puede construir con el propio lenguaje y consultar lo ya declarado.

emit

function, variable, struct, union, enum y macro son macros de ALMA que se expanden a una llamada a emit. emit es una función que recibe código C como datos, así que un programa puede construirlo con todo lo que hay en ALMA: defun, defmacro, let, lambda, if, list, quasiquote... 

; Genera una función que devuelve una constante por cada elemento de la lista
(defun constantes (lista)
  (if lista
    (progn
      (emit `(function ,(car (car lista)) int () (return ,(car (cdr (car lista))))))
      (constantes (cdr lista)))))

(constantes '((uno 1) (dos 2) (tres 3)))

Introspección

Desde ALMA se puede consultar lo que emit conoce, incluida la biblioteca estándar. Las funciones reciben nombres como símbolos y devuelven los tipos con la sintaxis de ALMA, así que sirven para generar código. Devuelven nil si lo consultado no existe.

Por ejemplo, una función de ALMA puede generar una función de C que imprima todos los campos de cualquier struct a partir de (c-record-members 'Punto).

Solo se ven las declaraciones globales de las formas ya emitidas: las macros se expanden antes de emitir su forma, así que no ven las variables locales.
