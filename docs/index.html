ALMA: un Lisp que genera C

Un programa de ALMA se ejecuta al compilar. El código C que produce son datos de ALMA (listas), así que se puede construir, transformar y generar con el propio lenguaje antes de convertirlo en C.

ALMA
(function main int ()
  (puts "Hola mundo")
  (return 0))
C
#include <stdio.h>

int main(void)
{
    puts("Hola mundo");
    return 0;
}

El código generado se comprueba antes de escribirse: tipos, declaraciones, ámbitos, etiquetas... Solo se añaden los #include de la biblioteca estándar que se usan.

ALMA es una prueba de concepto en desarrollo.

Qué tiene

C con sintaxis de Lisp Funciones, structs, unions, enums, punteros y macros, con comprobación de tipos. Generar C emit recibe código C como datos y la introspección consulta lo ya declarado. Un Lisp al compilar Quasiquote, let, lambda, macros, characters, keywords y símbolos no internados. Parámetros flexibles Argumentos opcionales, por keyword, &rest y &rest-keys. Estructuras de datos Listas, vectores y tablas hash con eq, eql, equal, equalp o tu propio test. Packages Como en Common Lisp, con nombres locales, símbolos privados y macro characters heredables.
