Limitaciones, organización del código y licencia.

Limitaciones

  • No hay literales de C con decimales, hexadecimales ni de carácter.
  • No hay volatile, restrict, inicializadores de arrays o structs, ni arrays o structs globales definidos.
  • Un enum no se puede declarar sin definir sus constantes, como en C estándar.
  • No se pueden incluir cabeceras que no sean de la biblioteca estándar: las funciones de otras bibliotecas se declaran con function sin cuerpo.
  • Los nombres de tipo son de una sola palabra (long, pero no unsigned long).
  • 0 no se acepta como puntero nulo: hay que usar NULL.
