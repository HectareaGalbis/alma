El lenguaje C

Cómo se escriben en ALMA los tipos, las declaraciones, las expresiones y las sentencias de C.

Tipos

Los tipos se escriben como listas: el nombre y después los especificadores. const va antes del nombre para calificar el tipo base, o después de * para calificar ese puntero.

ALMAC
intint
(char *)char *
(char * *)char **
(int 10)int [10]
(int ((char *) int))int (char *, int)
(int ((char *) &rest))int (char *, ...)
(void (int) *)void (*)(int)
(const int)const int
(const char *)const char *
(char * const)char *const
(const char * const)const char *const

No se puede asignar a nada const (tampoco a través de punteros ni a miembros de un struct const), y char * se convierte en const char *, pero no al revés.

Definiciones y declaraciones

(function suma int ((a int) (b int))      ; definición
  (return (+ a b)))
(function externa int ((x int)))          ; sin cuerpo: declaración
(function nada void () ())                ; cuerpo vacío

(variable contador int 0)                 ; variable global (valor constante)
(variable externa int)                    ; sin valor: extern int externa;

(struct Punto (x int) (y int))            ; struct + typedef
(union Valor (i int) (f float))
(enum Color ROJO VERDE (AZUL 5) NEGRO)    ; enum + typedef

Un enum es un tipo entero y sus constantes son constantes int: se pueden usar en un case o para inicializar variables globales. El valor de una constante debe ser un entero constante y puede usar las anteriores.

Dentro de una función, (variable i int 0) define una variable local, con o sin valor.

Comprobaciones

Antes de escribir el C, alma2c comprueba, entre otras cosas:

  • que las funciones y variables usadas estén declaradas,
  • el número y el tipo de los argumentos de las llamadas,
  • los tipos de los operadores y de las asignaciones, con las reglas básicas de C,
  • que no haya redefiniciones ni declaraciones incompatibles,
  • que no se modifique nada const ni se pierda const en una conversión,
  • que return devuelva el tipo de la función,
  • que break, continue y goto estén donde pueden estar,
  • que las variables globales se inicialicen con constantes.

Biblioteca estándar

Las funciones, variables y macros de la biblioteca estándar de C ya están declaradas (printf, malloc, strlen, sqrt, EOF, NULL...), con const donde C lo tiene. Solo se añaden al C los #include de lo que se usa.

Macros del preprocesador

macro define una macro cuyo cuerpo es código de ALMA que devuelve el código C que la sustituye. Funciona como el preprocesador de C: los argumentos se expanden antes, el resultado se vuelve a expandir y una macro no se expande dentro de su propia expansión. Una macro tiene preferencia sobre una función con el mismo nombre. 

(macro cuadrado (x) `(* ,x ,x))
(macro when (condicion &rest cuerpo) `(if ,condicion (block ,@cuerpo)))

La lista de parámetros de macro solo admite símbolos y un &rest al final. Las macros de ALMA, que se ejecutan al compilar, se explican en Funciones y macros.
