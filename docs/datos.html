Listas, vectores y tablas hash

Las estructuras de datos de ALMA para manipular datos al compilar.

Listas

Una lista es una cadena de pares (conses) que termina en nil. (cons 1 2) crea un par, que se escribe (1 . 2).

FunciónDescripción
(cons a b), (list a b ...)crear un par o una lista
(car x), (cdr x)primer elemento y resto de un par; de nil devuelven nil
first, second, third, restelementos 0, 1 y 2, y todo menos el primero
(nth n lista), (nthcdr n lista)elemento n y lista a partir del elemento n
(last lista)el último par
(length lista)número de elementos
(append a b ... final)une las listas; el último argumento es el final y puede no ser una lista
(reverse lista)lista nueva en orden inverso
(member x lista)la lista desde el primer elemento eq a x, o nil
(rplaca par x), (rplacd par x)cambian el car o el cdr del par y lo devuelven
consp, listp, null, atomsi es un par, una lista (par o nil), nil, o no es un par
(endp lista)si la lista está vacía; es un error si no es una lista
(append '(1 2) '(3) 4)       ; (1 2 3 . 4)
(member 'b '(a b c))         ; (b c)
(nth 1 '(a b c))             ; b
(last '(a b c))              ; (c)
(rplaca (list 1 2) 9)        ; (9 2)

Igualdad

FunciónDos objetos son iguales si...
eqson el mismo objeto
eqlson eq, o son enteros o characters con el mismo valor
equalson eql, strings con el mismo contenido o listas con elementos equal
equalpcomo equal sin distinguir mayúsculas en characters y strings, y también vectores y tablas hash con el mismo contenido
(eq 1 1)                     ; nil: cada 1 es un objeto distinto
(eql 1 1)                    ; t
(equal '(1 (2 "x")) '(1 (2 "x")))   ; t
(equalp '(\A "AB") '(\a "ab"))      ; t
(equalp #(1) #(1))           ; t

Vectores

Los vectores están implementados con una cola doble. Aplicar un vector a un índice devuelve su elemento. 

(set-symbol-value 'v (vector 1 2 3))     ; [1 2 3]
(v 0)                                    ; 1
(vector-set v 1 'dos)                    ; [1 dos 3]
(vector-push-back v 4)                   ; [1 dos 3 4]
(vector-pop-front v)                     ; 1
#(a b c)                                 ; [a b c]
FunciónDescripción
(vector a b ...), (make-vector n [valor]), #(a b ...)crear un vector
(v i), (vector-set v i x)leer y escribir un elemento
vector-front, vector-backprimer y último elemento
vector-push-front, vector-push-backañadir al principio o al final
vector-pop-front, vector-pop-backquitar del principio o del final
(vector-insert v i x), (vector-erase v i)insertar antes de i y quitar
vector-length, vector-empty-p, vectorpconsultas
vector-clear, vector-to-list, list-to-vectorvaciar y convertir

Las funciones que modifican el vector lo devuelven; las que quitan un elemento devuelven ese elemento. Los vectores son datos de ALMA y no se pueden emitir como C.

Tablas hash

Una tabla hash asocia claves a valores. Dos claves son la misma si lo dice el test de la tabla, que por defecto es eql. 

(set-symbol-value 'h (make-hash-table :test 'equal))
(puthash "uno" 1 h)          ; 1
(gethash "uno" h)            ; 1
(gethash "dos" h 'nada)      ; nada
(hash-table-count h)         ; 1
#{"a" 1 "b" 2}               ; <hash-table equal 2>

Crear una tabla

make-hash-table recibe argumentos por keyword:

ArgumentoDescripción
:testeq, eql, equal, equalp (el símbolo o la función) o una función propia que recibe dos claves
:hash-functionfunción que recibe una clave y devuelve un entero, el mismo para las claves que el test considera iguales. Es obligatoria con un test propio
:sizenúmero de entradas para las que reservar espacio
; Claves iguales si tienen el mismo primer elemento
(make-hash-table :test (lambda (a b) (eq (car a) (car b)))
                 :hash-function (lambda (k) 0))

#{...} crea una tabla con el test equal a partir de pares de clave y valor, que no se evalúan.

Funciones

FunciónDescripción
(gethash clave tabla [defecto])el valor de la clave, o defecto (nil si no se da)
(puthash clave valor tabla)asocia el valor a la clave y lo devuelve
(remhash clave tabla)quita la clave; t si estaba
(clrhash tabla)vacía la tabla y la devuelve
(maphash f tabla)llama a (f clave valor) por cada entrada; devuelve nil
(hash-table-contains-p clave tabla)si la clave está
(hash-table-count tabla)número de entradas
(hash-table-test tabla)el símbolo del test, o la función si es propio
(hash-table-p x)si es una tabla hash
