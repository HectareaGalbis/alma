ALMA al compilar

Todo lo que no es C se ejecuta al compilar. Esta página explica cómo se lee y se evalúa ese código.

Strings

Dentro de un string, \n es un salto de línea, \t un tabulador, \" unas comillas y \\ una barra.

Characters

Una barra seguida de un carácter es ese carácter, aunque sea un delimitador: \a, \(, \;. Si después vienen más letras, es el nombre de un carácter:

NombreCarácter
\spaceespacio
\newlinesalto de línea
\tabtabulador
\returnretorno de carro
\backspaceretroceso
\nulcarácter nulo
(list \a \space \newline \( \tab)       ; (\a \space \newline \( \tab)

Símbolos

Un símbolo se busca en el package actual y, si no está, se crea en él. Con pkg:nombre se usa un símbolo exportado de otro package, y pkg::nombre es un error: los símbolos que no se exportan son privados. Un keyword (:nombre) pertenece al package keyword y se evalúa a sí mismo. ::nombre crea un símbolo que no pertenece a ningún package. Todo esto se explica en Packages.

Vectores, tablas hash y macro characters

# seguido de un carácter llama al macro character de ese carácter. Tras #(, #[ y #{ se leen objetos hasta su pareja. El package alma define #( (vectores) y #{ (tablas hash con el test equal). Sus elementos no se evalúan. 

#(1 (+ 1 1))                 ; [1 (+ 1 1)]
(gethash "a" #{"a" 1 "b" 2}) ; 1

Cómo definir macro characters nuevos se explica en Macro characters.

Evaluación

  • Los enteros, strings, characters, keywords, vectores y tablas hash se evalúan a sí mismos. También t (verdadero) y nil (falso y lista vacía).
  • Un símbolo se evalúa a su valor: el de una variable local (de let o de un parámetro) o, si no hay, su valor global.
  • Una lista es una llamada. Se evalúa el primer elemento y, según lo que sea:
    • una función recibe los argumentos evaluados,
    • una macro recibe los argumentos sin evaluar y su resultado se vuelve a evaluar,
    • un operador especial recibe los argumentos sin evaluar y su resultado no se vuelve a evaluar,
    • un vector recibe un índice y devuelve ese elemento.
(set-symbol-value 'v (vector 1 2 3))
(v 1)                        ; 2

Cargar archivos

load ejecuta otro archivo de ALMA como si su contenido estuviera en el punto donde se llama: lo que defina (funciones de ALMA, macros, declaraciones de C) queda disponible después. Una ruta relativa se resuelve desde el directorio del archivo que llama a load, no desde el directorio actual. Al terminar, *package* vuelve a ser el package que había antes de cargarlo.

*current-file* contiene la ruta absoluta del archivo que se está cargando.

(load "lib/util.alma")       ; relativo a este archivo
(print *current-file*)

Importar proyectos

(import-project "nombre") descarga un proyecto con git y carga su archivo nombre.alma. El proyecto se busca en la distribución de *source-distribution*, que por defecto es https://github.com/HectareaGalbis/alma-projects.

Una distribución es un repositorio con un archivo projects.alma que tiene una entrada por proyecto o por otra distribución: 

("nombre" project "https://github.com/usuario/nombre" "main")
("otra" distribution "https://github.com/usuario/otra" "v1.0")

El último elemento es la rama o el tag. (import-project "otra/nombre") busca nombre dentro de la distribución otra. Los repositorios se guardan en $XDG_CACHE_HOME/alma (o ~/.cache/alma) y no se vuelven a descargar si ya están.
