ALMA GitHub

Primeros pasos

Compilar ALMA, escribir el primer programa y usar el REPL.

Compilar

Hace falta CMake (3.10 o posterior) y g++ con soporte de C++23. Para compilar el C generado hace falta gcc. 

mkdir -p build && cd build
cmake .. && make

Esto genera build/src/alma2c, que traduce un archivo de ALMA a C:

build/src/alma2c programa.alma -o programa.c

El tipo de compilación se elige con CMAKE_BUILD_TYPE:

TipoOpciones
Release (por defecto)-O2, NDEBUG
Debug-g y avisos
FastDebug-O2, avisos y -fsanitize=address
cmake -DCMAKE_BUILD_TYPE=Debug ..

Instalar

cmake --install copia alma2c y el script alma en <prefijo>/bin:

cmake --install build                      # en /usr/local/bin (puede necesitar sudo)
cmake --install build --prefix ~/.local    # en ~/.local/bin

El primer programa

Guarda esto en hola.alma:

(function main int ()
  (puts "Hola mundo")
  (return 0))

Y compílalo y ejecútalo:

./alma -o hola hola.alma
./hola

puts no se declara: la biblioteca estándar de C ya está declarada y ALMA añade #include <stdio.h> porque se usa.

El script alma

El script alma traduce los archivos .alma con alma2c y llama a gcc. Todos los demás argumentos se pasan a gcc sin cambios, así que se pueden mezclar archivos .alma, .c y .o y usar cualquier opción de gcc: 

./alma -o hola examples/01_hola_mundo.alma           # ejecutable
./alma -c programa.alma                              # objeto programa.o
./alma -Wall -O2 -o prog main.alma util.c -lm        # cualquier opción de gcc
./alma --emit-c programa.alma                        # solo genera programa.c

alma2c se busca en $ALMA2C, junto al script, en build/src/ y en el PATH.

El REPL

alma2c sin argumentos abre un REPL: lee una forma, la evalúa y escribe el resultado. Las formas de C que se escriban se van acumulando. 

alma> (+ 1 2)
3
alma> (function main int () (puts "Hola") (return 0))
nil
alma> (exit t "hola")

exit termina el REPL:

FormaDescripción
(exit nil)sale sin generar nada
(exit t)compila con gcc el C acumulado (en a.out)
(exit t "nombre")compila el C acumulado en el ejecutable nombre

En un archivo, (exit t) deja de leerlo y escribe el C generado hasta ese punto, y (exit nil) lo deja de leer sin escribir nada y alma2c termina con error.
